# For the Outer Sunset notes, not for this repo

`outer-sunset/` here is a set of changes meant for the data repo
([outer-sunset](https://github.com/The-Relational-Technology-Project/outer-sunset)), carried on this
branch only because the session that wrote them could not push there. Copy the files over the same
paths in the data repo, open a pull request there, and delete this folder before merging this branch.

- `archive/history-*.md`, `archive/ecology-*.md`: sixteen sourced notes, gathered November 10, 2026.
  Each note's research gaps and the places where sources disagree are written into its sections.
- `place.md`, `STEWARDS.md`, `README.md`, `archive/README.md`: asking a neighbor, the commons.
- `knowers/`, `knowledge/`: the two new folders, each with a README.
