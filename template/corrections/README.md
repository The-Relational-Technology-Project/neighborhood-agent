# Corrections

One file per correction. A correction here beats anything the agent fetched.

```
---
target: "The Diner"
field: hours
was: "unknown"
now: "6am to 2pm, closed Mondays"
how_known: "asked at the counter"
by: a neighbor
date: 2026-01-16
---
```

`how_known` is how the person knows, not who told them.
