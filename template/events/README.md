# Events

One file per event, named `YYYY-MM-DD-short-title.md`. The agent drafts these when someone asks to add an event; a steward merges.

```
---
title: River Day
date: 2099-06-01
start: "10:00"
place: the gravel bar
host: Friends of the River
contact: https://example.org/river
source: told to the agent by the host
added: 2026-01-20
---

Cleanup, then lunch.
```

A host is named only if they gave a name for that purpose.
